Privacy

Ultron is a personal assistant used by one person, on that person's own computer.

What Ultron can access

With its owner's Google sign-in, Ultron can:

  • read Gmail messages, write drafts and send mail;
  • read and create Google Calendar events;
  • read files in Google Drive.

How that information is used

It is used only to answer the owner's own requests, such as finding a message or listing the day's events. Sending mail and creating events happen only after the owner approves each one.

Where it is kept

The sign-in and anything Ultron reads stay on the owner's computer. Nothing is stored on this website or on any server run for Ultron.

Sharing

Google account information is not sold, not shared with anyone else, and not used for advertising. Ultron's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google account's third-party access page. Deleting the sign-in file on the computer has the same effect locally.

This website

This site is two static pages. It sets no cookies and collects nothing.
